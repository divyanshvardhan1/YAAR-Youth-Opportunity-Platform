# Testing checklist – Y.A.A.R. academic prototype

Run unit tests with `python -m unittest discover -s tests -v`.

## Manual demonstration checklist

- [ ] Home page loads on desktop and a mobile-width browser.
- [ ] Youth can register, sign in and sign out.
- [ ] NGO can register, sign in and sign out.
- [ ] Youth can save updated skills, interests, city and availability.
- [ ] NGO can publish an opportunity with required fields.
- [ ] Opportunity appears for a signed-in youth.
- [ ] Recommendations change when youth preferences change.
- [ ] Youth can apply to an opportunity once (duplicate application blocked).
- [ ] NGO can accept or reject a pending application.
- [ ] Youth can view the updated application status.
- [ ] Invalid/missing form fields trigger a useful error message.
- [ ] A signed-out user cannot access restricted actions.
- [ ] Website loads from an independent phone/network.

## Evidence to collect for university report

- Screenshots of forms, dashboards, recommendations, applications and statuses.
- Actual test date, case, input, expected output, observed output and pass/fail.
- Any observed limitations or known issues; do not claim untested outcomes.

Do not use personal data from real youth/NGO accounts while capturing public screenshots.
